# Neural Relational Inference

This is a repo for my final project submission for William and Mary's DATA 621 (Neural Networks and Deep Learning) course, Spring 2025.  It is a reimplementation in modern PyTorch of the NRI model in [this paper](https://proceedings.mlr.press/v80/kipf18a.html).  The author's original code is available [here](https://github.com/ethanfetaya/NRI/).
